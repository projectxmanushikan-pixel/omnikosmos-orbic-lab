# OMNIKOSMOS Orbic Intelligence Lab

An early-stage experimental concept for a spherical AI companion and a future modular physical body.

## Run the digital prototype
Open `index.html` in a modern web browser. It is a static website suitable for GitHub Pages.

## What works now
- Responsive browser interface with animated conceptual orb
- Local system-check counter and event log
- Transparent keyword-rule demonstration in the reasoning console
- Text report export

## Not implemented
- No connected AI model or API
- No physical sensors, motors, propulsion, levitation, or autonomous movement
- No proof of electromagnetic transport or dimensional travel
- The orb is a visual concept, not a tested physical design

## Suggested development stages
1. Validate the digital interface and gather feedback.
2. Define measurable requirements and a safety plan.
3. Build a stationary, low-voltage bench prototype from commercially available components.
4. Add one sensor at a time and document calibration and test results.
5. Develop and test a modular spherical enclosure, thermal management, and fail-safe controls.
6. Consider mobility only after stationary testing and hazard review.
