# OMNIKOSMOS Orbic Intelligence — Roadmap

## Phase 1: Digital demonstrator
- [x] Responsive static web interface
- [x] Rule-based observation console
- [x] Event log and report export
- [ ] Collect external feedback and usability observations

## Phase 2: Requirements and architecture
- [ ] Define the stationary prototype's purpose and measurable success criteria
- [ ] Compare compute platforms, sensors, power options, and thermal limits
- [ ] Create wiring diagram and bill of materials before buying components
- [ ] Define emergency shutdown, enclosure, and electrical safety requirements

## Phase 3: Stationary proof of concept
- [ ] Boot a supported computing board safely on a bench
- [ ] Integrate one sensor at a time
- [ ] Log measurements with timestamps and calibration notes
- [ ] Add an AI service only after reviewing privacy, network, cost, and safety requirements

## Phase 4: Modular body
- [ ] CAD enclosure and mounting system
- [ ] Check weight distribution, airflow, access, and serviceability
- [ ] Test stability and temperature before any movement

## Phase 5: Controlled motion research
- [ ] Establish a physically plausible mechanism and measurable test
- [ ] Use guards, low speed, a controlled test area, and a hardware emergency stop
- [ ] Publish repeatable results, including failures

Electromagnetic propulsion, levitation, and transport are not demonstrated by this project. Treat each as a separate hypothesis requiring theory, instrumented experiments, and independent verification.
