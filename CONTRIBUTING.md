# Contributing to OMNIKOSMOS

Thank you for helping evaluate this experimental concept.

## Useful contributions
- Reproducible software bugs and browser compatibility notes
- Accessibility and usability improvements
- Evidence-based component comparisons
- Sensor calibration and test procedures
- CAD proposals with dimensions and tolerances
- Safety reviews and documented test results

## How to report a test
Include date, hardware/software version, test setup, expected result, observed result, measurement units, limitations, and any safety concern.

## Ground rules
- Clearly distinguish ideas, simulations, and measured results.
- Do not claim capabilities that have not been demonstrated.
- Do not publish secrets, API keys, passwords, or private personal information.
- Do not connect experimental electronics to mains power without qualified review.
